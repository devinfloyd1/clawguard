## Configuration File Format
clawdbot.json contains:
- Agent configuration
- Channel settings (telegram, discord, slack, etc.)
- Gateway authentication
- Auth profiles (API keys)
- Plugin settings

## Session Log Format
- JSONL (JSON Lines) format
- Located in: ~/.clawdbot/agents/<agent-id>/sessions/
- Includes conversation history, tool calls, etc.

## Alternative Paths (for compatibility)
- ~/.openclaw/ -> Not used in this installation
- ~/.clawdbot/ -> Primary configuration directory
- Skills can also be in: /usr/lib/node_modules/clawdbot/skills/
